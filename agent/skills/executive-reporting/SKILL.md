# Executive Reporting Protocol

## The 5-Minute Executive Structure:

Every completed analysis must generate an executive report via `generate_executive_brief` that adheres to this exact 4-tier hierarchy:

### 1. The 30-Second Bottom Line (Key Takeaways)
* 2-3 high-impact bullet points summarizing the core conclusion and financial / operational implication.

### 2. Diagnostic Findings & Visual Proof
* Grouped findings with embedded chart artifacts.
* Each finding must state:
  - **What the chart shows:** (Observation)
  - **Why it matters:** (Underlying cause / correlation)

### 3. Prioritized Action Matrix
* 3-4 concrete prescriptive recommendations categorized by:
  - **Priority:** High, Medium, Low
  - **Action:** Specific operational intervention
  - **Expected Impact:** Estimated churn reduction, revenue boost, or cost savings

### 4. Data Hygiene & Caveats
* Transparent disclaimer of sample size, missing data assumptions, or areas needing further telemetry.
